## Setup Steps

1. Find a **City biome** map (for the extra tablet slot)
2. Apply **200% Delirium** via Grand Mirror
3. Add **Ritual** via Head of the King (not ritual tablets)
4. Use **Unforeseen Consequences** unique tablet
5. Fill remaining slots with **S+/S tier** abyss tablets
6. Target **~15 additional Abysses** per map
7. Stack **~240% Item Rarity** on gear
